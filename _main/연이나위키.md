## 개인 위키입니다

공부한 것에 대한 간단한 서술을 적습니다. 나름대로 각 분야에 애정을 가지고 적으려고 하고 있습니다.

## 잼이 없는 위키입니다

여가를 위해서, 또는 재미를 위해서 서술하는 위키는 아니게 될 예정입니다. 나중에 해당 분야를 본격적으로 공부하게 될 지도 모르기 때문에, 최소한의 신뢰성을 확보하기 위함입니다.

## 연이나 이외의 기여는 거의 불가능합니다

틀린 정보가 있다면 howeverina@proton.me 로 자료를 보내주시거나, 본 github repo (howeverina/wiki) 에 직접 issue 같은 걸 넣어 주세요. 최대한 빠르게 반영하겠습니다.
