{% include stub %}

기준음인 황종을 가지고 12음을 산출하는 방법이다. 서양과 달리 관악기의 원리를 이용한다.

## 산출 방법

### 삼분익일

기준이 되는 관의 1/3만큼 긴 관의 길이를 취하는 방식. 완전4도 낮은 소리를 얻는다.

### 삼분손일

기준이 되는 관의 1/3만큼 짧은 관의 길이를 취하는 방식. 완전5도 높은 소리를 얻는다.

## 산출 순서

괄호 안의 음이름은 향악이 아닌 아악, 당악 기준의 황종(황종=C)을 기준으로 작성했다. 산출 원리가 원리이다 보니, 기본적으로 5도권으로 돌아간다고 생각하면 편리.

* 황종(C) -> 임종(G) (삼분손일)
* 임종(G) -> 태주(D) (삼분익일)
* 태주(D) -> 남려(A) (삼분손일)
* 남려(A) -> 고선(E) (삼분익일)
* 고선(E) -> 응종(B) (삼분손일)
* 응종(B) -> 유빈(Gb) (삼분익일)
* 유빈(Gb) -> 대려(Db) (삼분익일)[^1]
* 대려(Db) -> 이칙(Ab) (삼분손일)
* 이칙(Ab) -> 협종(Eb) (삼분익일)
* 협종(Eb) -> 무역(Bb) (삼분손일)
* 무역(Bb) -> 중려(F) (삼분익일)
* 중려(F) -> 청황종(C) (삼분손일)
